# 📚 Library Management System (Python)

## 📌 Overview

This is a simple **Library Management System** built using Python.
It allows users to:

* Add books
* View available books
* Issue books
* Return books

This project is beginner-friendly and demonstrates basic concepts like:

* Functions
* Lists
* Loops
* Conditional statements

---

## ⚙️ Features

* ✅ Add new books to the library
* 📖 Display all available books
* 📕 Issue books (remove from available list)
* 🔄 Return issued books
* ❌ Exit the program

---

## 🛠️ Technologies Used

* Python (Core Python concepts)

---

## ▶️ How to Run

1. Make sure Python is installed on your system
2. Save the file as `library.py`
3. Open terminal / command prompt
4. Run the program:

```bash
python library.py
```

---

## 🧑‍💻 How It Works

The program runs in a loop and shows a menu:

1. Add Books
2. Show Books
3. Issue Books
4. Return Books
5. Exit

User selects an option and the program performs the action accordingly.
